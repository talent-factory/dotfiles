# Stepper-Pattern implementieren

Implementiere Stepper für: $ARGUMENTS

## Stepper-Implementierung

1. **Workflow analysieren**:
   - Schritte des Prozesses identifizieren
   - Abhängigkeiten zwischen Schritten definieren
   - Validierungsregeln festlegen

2. **UI-Komponente erstellen**:
   - Schritt-Indikatoren (Nummerierung/Icons)
   - Navigation zwischen Schritten
   - Progress-Anzeige
   - Validierungs-Feedback

3. **State Management**:
   - Aktueller Schritt verwalten
   - Schritt-Validierung implementieren
   - Daten zwischen Schritten übertragen

4. **Benutzerführung**:
   - Klare Anweisungen pro Schritt
   - Fehlerbehandlung und -anzeige
   - Möglichkeit zum Zurückgehen
   - Zusammenfassung am Ende
