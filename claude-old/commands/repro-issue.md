# Fehler reproduzieren

Reproduziere Issue: $ARGUMENTS

## Reproduktions-Workflow

1. **Issue-Details sammeln**:
   - Fehlerbeschreibung verstehen
   - Betroffene Umgebung identifizieren
   - Erwartetes vs. tatsächliches Verhalten

2. **Reproduktionsschritte erstellen**:
   - Minimale Schritte zur Fehlerauslösung
   - Testdaten und -umgebung vorbereiten
   - Systematisch testen

3. **Dokumentation**:
   - Reproduktionsschritte dokumentieren
   - Screenshots/Logs sammeln
   - Fehlerursache eingrenzen

4. **Validierung**:
   - Reproduktion in verschiedenen Umgebungen
   - Edge Cases identifizieren
   - Workarounds dokumentieren
