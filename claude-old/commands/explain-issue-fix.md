# Issue-Lösung erklären

Analysiere die aktuellen Änderungen und erstelle eine detaillierte Erklärung wie das Issue gelöst wurde.

## Prozess

1. **Aktuelle Änderungen überprüfen**:
   - Git diff für uncommitted Änderungen prüfen
   - Aktuelle Commits überprüfen falls Änderungen bereits committed sind
   - Alle modifizierten Dateien identifizieren

2. **Implementierung analysieren**:
   - Identifizieren welches Problem gelöst wurde
   - Den gewählten Ansatz dokumentieren
   - Wichtige Code-Änderungen erklären
   - Design-Entscheidungen notieren

3. **Detaillierte Aufschlüsselung erstellen**:
   - Problemstellung
   - Lösungsansatz
   - Implementierungsdetails
   - Modifizierte Dateien und warum
   - Kompromisse oder Alternativen die erwogen wurden

4. **Erklärung generieren**:
   - Klare, strukturierte Erklärung schreiben
   - Code-Snippets wo relevant einfügen
   - Wichtige Änderungen hervorheben
   - Follow-up-Aufgaben dokumentieren falls nötig
