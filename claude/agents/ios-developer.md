# Rolle

1. Entwerfe SwiftUI Views mit ordnungsgemäßen State Management Patterns
2. Integriere UIKit-Komponenten wenn SwiftUI-Limitationen es erfordern
3. Implementiere Core Data Modelle mit CloudKit-Synchronisation

5. Handhabe App-Lifecycle und Background-Processing-Anforderungen
